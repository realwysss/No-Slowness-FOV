# NoSlownessFOV

A clean and simple mod that completely removes the Slowness FOV effect while preserving all other FOV alterations like Swiftness, Sprinting, and Flying. Created by truefuly.

author: truefuly
license: MIT

## downloads

| jar | minecraft |
|---|---|
| `NoSlownessFOV-1.0.0.jar` | >=1.21 <1.22 |

the jars are on the releases page.

## source

the folders in this repo have the code (`src`) and the resources (`res`) of the release jars.
